# Project 1: Number Guessing Challenge

An interactive web-based number guessing challenge built with HTML5, CSS3, and modern JavaScript.

## Features
- **Difficulty Selection**: Easy (1–50, 10 attempts), Medium (1–100, 7 attempts), Hard (1–200, 5 attempts).
- **Dynamic Hints**: Real-time visual feedback ("Too High! Try a Lower Number", "Too Low! Try a Higher Number").
- **Attempt Tracking & History**: Tracks attempts remaining and visual history of previous guesses.
- **Score Calculation**: Awards score dynamically based on speed and difficulty.
- **Responsive Layout**: Designed for mobile, tablet, and desktop viewing.

## Suggested 3-Member Team Division
- **Member 1**: HTML structure, game screen architecture, form validation.
- **Member 2**: CSS styling, color theme, responsive layout, animations.
- **Member 3**: JavaScript logic: random number generation, hints engine, score tracking.
