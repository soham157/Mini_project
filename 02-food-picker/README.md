# Project 2: Food Picker – What Should I Eat?

An interactive culinary recommendation website that solves decision fatigue by suggesting meals based on meal category and dietary filters.

## Features
- **Meal Categories**: Breakfast, Lunch, Evening Snacks, and Dinner.
- **Dietary Filter**: Vegetarian and Non-Vegetarian filtering options.
- **"I'm Feeling Lucky"**: Cross-category universal randomizer.
- **Favorites Collection**: Bookmark favorite dishes with persistent browser storage.
- **Ingredients & Descriptions**: Displays key ingredients, regional descriptions, and badges.

## Suggested 3-Member Team Division
- **Member 1**: HTML structure, home page layout, category tabs, and navigation bar.
- **Member 2**: CSS styling, food cards, badge design, and responsive grid.
- **Member 3**: JavaScript random selection algorithms, filtering logic, and favorites manager.
