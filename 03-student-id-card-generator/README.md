# Project 3: Student ID Card Generator

A digital student identity card builder designed to reduce manual ID card creation overhead while producing printable front & back identity credentials.

## Features
- **Comprehensive Form**: Institutional name, student ID, enrollment number, blood group, guardian details, and emergency contacts.
- **Photo Upload**: Real-time client-side image preview in circular photo framing.
- **3D Flip Card**: Interactive front and back view with institutional terms, barcode/QR simulator, and authority signatures.
- **Print Optimization**: Dedicated CSS print styles to export the generated ID card directly as a clean PDF or printout.

## Suggested 3-Member Team Division
- **Member 1**: HTML input form, field validations, structure.
- **Member 2**: CSS 3D card layout, front/back styles, responsive design, print media query.
- **Member 3**: JavaScript live data-binding, photo file reader API, card flipping and print actions.
