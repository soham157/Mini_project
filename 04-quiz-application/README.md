# Project 4: Quiz Application

A responsive, interactive multiple-choice quiz application featuring multiple categories, timer countdowns, and instant score analysis.

## Features
- **5 Categories**: Computer Science, General Knowledge, Science, Mathematics, Sports.
- **Progress Tracking**: Real-time progress bar and current question counter.
- **Countdown Timer**: 2-minute exam timer with automatic submission on timeout.
- **Answer Review**: Complete breakdown of correct, incorrect, and unanswered questions.
- **Responsive Layout**: Designed for seamless quiz-taking on mobile or desktop.

## Suggested 3-Member Team Division
- **Member 1**: Welcome page, category selection grid, HTML questions layout.
- **Member 2**: CSS styling, option highlight states, responsive design, progress animations.
- **Member 3**: JavaScript quiz logic, countdown timer, answer verification, and score reporting.
