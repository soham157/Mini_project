# Project 5: Restaurant Menu Website

An interactive digital culinary menu showcasing food items, category filtering, search features, and special combos.

## Features
- **Categorized Sections**: Starters, Main Course, Chinese, Fast Food, Desserts, Beverages.
- **Instant Search**: Real-time keyword filtering across names and descriptions.
- **Item Details Modal**: Detailed breakdown of ingredients, spice levels, and vegetarian status.
- **Combo Deals Section**: Prominent discounted offers and meal bundles.
- **Contact & Inquiry**: Validated reservation form and venue location info.

## Suggested 3-Member Team Division
- **Member 1**: Homepage layout, navigation bar, About Us, and Contact sections.
- **Member 2**: Food categories, card styling, responsive grid, and modal styling.
- **Member 3**: JavaScript category filtering, live search algorithm, and modal state management.
