# Project 6: Daily Expense Tracker

A modern personal finance dashboard to log transactions, compute automatic expenditures, and visualize categorical spending patterns.

## Features
- **Dashboard Metrics**: Total spend, transaction count, highest single expense, and top spending category.
- **Categorical Breakdown**: Visual progress bars representing spend proportions across 8 categories.
- **CRUD Functionality**: Full add, edit, and delete support with browser local storage persistence.
- **Category Filter**: Instant filtering of historical transaction logs.
- **Responsive Layout**: Designed for seamless tracking on mobile, tablet, and desktop screens.

## Suggested 3-Member Team Division
- **Member 1**: Dashboard KPI cards, HTML form structure, and input field validation.
- **Member 2**: CSS layout, category badge styling, progress bars, and responsive table styling.
- **Member 3**: JavaScript calculation algorithms, category aggregations, CRUD handlers, and local storage.
