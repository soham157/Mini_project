# Project 7: Guess the Movie – Picture Challenge

An entertaining picture-and-clue based quiz game challenging users to identify iconic movies across Hollywood, Bollywood, and Animated genres.

## Features
- **Genre Categories**: Hollywood Blockbusters, Bollywood Classics, Animated Features.
- **Visual Clue Presentation**: Stylized emojis, scene descriptions, and dialogue clues.
- **Hint System**: Reveals release year, director, and storyline hints.
- **Countdown Timer**: 20-second timer per question with auto-timeout handling.
- **Score Calculation & Analytics**: Dynamic scoring (+10 per correct answer), accuracy percentage, and hints tracker.

## Suggested 3-Member Team Division
- **Member 1**: Welcome screen, movie categories collection, clue copy, and HTML structure.
- **Member 2**: CSS layout, card design, responsive option grid, and feedback animations.
- **Member 3**: JavaScript countdown timer, hint controller, answer checking, and score reporting.
