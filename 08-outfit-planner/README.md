# Project 8: Outfit Planner – What Should I Wear Today?

A smart wardrobe styling application that coordinates tops, bottoms, footwear, and accessories tailored to occasions and weather conditions.

## Features
- **Occasion-Based Recommendations**: College, Office, Party, Wedding, Sports/Gym, and Casual Outing.
- **Weather Awareness**: Curates breathable sunny wear, water-resistant rainy attire, or layered cold-weather outfits.
- **Random & Custom Modes**: Switch between one-click automated styling or manual piece-by-piece wardrobe pairing.
- **Ensemble Preview & Rating**: Displays a cohesive ensemble card with stylist notes and star rating.
- **Favorites Storage**: Bookmark favorite outfit pairings with local browser persistence.

## Suggested 3-Member Team Division
- **Member 1**: Welcome layout, occasion tabs, weather selectors, and HTML wardrobe schema.
- **Member 2**: CSS styling, clothing slot cards, star rating UI, and mobile responsive layout.
- **Member 3**: JavaScript outfit generation engine, occasion conditions, custom mode selectors, and bookmark manager.
