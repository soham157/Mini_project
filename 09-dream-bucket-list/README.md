# Project 9: Dream Bucket List

A motivating web dashboard enabling users to record life aspirations, organize them by category and priority, and monitor overall completion progress.

## Features
- **Progress Tracking**: Real-time progress bar computing exact completion percentage.
- **Categorization & Priorities**: High, Medium, Low priority color-coding across 8 categories.
- **Completion Toggle**: Instant status change with visual strikethrough styling.
- **Search & Status Filtering**: Real-time keyword search and All/Pending/Completed filters.
- **Persistent Storage**: Retains bucket list goals and achievements in local storage.

## Suggested 3-Member Team Division
- **Member 1**: Welcome hero section, motivational banner, HTML form, and category tags.
- **Member 2**: CSS layout, progress bar styling, priority color tags, and card designs.
- **Member 3**: JavaScript CRUD operations, status toggle, search filter, and completion calculations.
