# Project 10: Spot the Difference

An engaging side-by-side visual perception puzzle game featuring multi-level vector rendered scenes, clickable difference markers, and precision feedback.

## Features
- **3 Difficulty Levels**: Living Room (3 differences), Cozy Bedroom (5 differences), Modern Office (7 differences).
- **Coordinate Hit Detection**: Accurate circular collision checks when clicking on either the original or modified scene.
- **Visual Feedback**: Pulse marker rings on correct identification and instant feedback text.
- **Hint Engine**: Pulsing radar circle revealing one unidentified difference location.
- **Timer & Scoring**: 60-second challenge timer with performance breakdown.

## Suggested 3-Member Team Division
- **Member 1**: Welcome screen, instructions, level selector cards, and HTML canvas scaffolding.
- **Member 2**: CSS layout, side-by-side positioning, pulse marker animations, and game controls.
- **Member 3**: JavaScript Canvas 2D scene rendering, click event coordinate transforms, collision detection, and hints engine.
