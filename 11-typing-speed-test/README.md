# Project 11: Typing Speed Test – Interactive Typing Game

A real-time typing speed and accuracy evaluator calculating Words Per Minute (WPM) and live character-by-character feedback.

## Features
- **Difficulty Passages**: Easy, Medium, and Hard passages with punctuation and complex vocabulary.
- **Customizable Timers**: 30s, 60s, or 120s test duration options.
- **Real-Time Highlighting**: Live character feedback (green for correct, red for typos, underlined active cursor).
- **Live Metrics Dashboard**: Real-time WPM, accuracy percentage, countdown clock, and mistake counter.
- **Session Best Score**: Persists your highest WPM in local browser storage.

## Suggested 3-Member Team Division
- **Member 1**: Welcome and configuration UI, typography rules, HTML structure.
- **Member 2**: CSS layout, character status colors, responsive live dashboard styling.
- **Member 3**: JavaScript keystroke event handling, real-time WPM and accuracy algorithms, timer engine.
