# Project 12: Space Adventure Game – Interactive Space Shooter

An action arcade space shooter written using the HTML5 Canvas API and JavaScript game loop physics.

## Features
- **Player Spaceship Controls**: 4-way arrow key movement with boundary collision clamping.
- **Blaster Weapon System**: Spacebar laser firing with projectile lifecycle management.
- **Dynamic Enemy Waves**: Procedurally spawned alien interceptors moving with speed curves.
- **Collision Detection**: 2D bounding-box collisions between lasers, enemy cruisers, and player starfighter.
- **Particle Explosions**: Canvas particle bursts on destruction.
- **Health & High Scores**: 3-heart shield integrity tracker and persistent session high scores.

## Suggested 3-Member Team Division
- **Member 1**: Welcome briefing, mission controls guide, HUD bar, and HTML structure.
- **Member 2**: CSS styling, overlay cards, HUD layout, canvas container styling.
- **Member 3**: JavaScript Canvas 2D game loop, projectile arrays, collision physics, and scoring logic.
