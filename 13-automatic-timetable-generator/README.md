# Project 13: Automatic Timetable Generator

An institutional scheduling software that builds conflict-free weekly timetables for academic courses, faculties, and lecture halls.

## Features
- **Academic Setup**: Configurable institutional details, semesters, working days (5 or 6), and period counts.
- **Subject & Period Allocation**: Defines course codes, credit periods, and theory/laboratory distinction.
- **Faculty & Room Constraint Management**: Maps teachers to specific subjects and assigns labs or lecture halls.
- **Automated Scheduling Engine**: Generates balanced period allocations while flagging schedule overloads.
- **Export & Print**: One-click direct browser printing (with dedicated print stylesheet) and CSV file export.

## Suggested 3-Member Team Division
- **Member 1**: HTML forms, institutional parameters, subject and teacher input layouts.
- **Member 2**: CSS grid styling, responsive timetable matrix, slot cards, and print stylesheet.
- **Member 3**: JavaScript conflict detection algorithms, period allocation engine, CSV exporter.
