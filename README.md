# Mini Projects – Web Development

13 browser projects built with plain HTML, CSS and JavaScript (no frameworks, no backend).
Each folder has `index.html`, `style.css` and `script.js` — open `index.html` in Chrome to run it.

## Team workflow
Each member works on a feature branch (`feature/<name>`), commits their own changes, and merges through a Pull Request into `main`.
