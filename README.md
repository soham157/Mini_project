# Bosscoder School of Technology – Web Development Mini Projects

This repository contains the complete, production-grade source code for all **13 Web Development Mini Projects** described in the Bosscoder Academy Mini Project Abstracts document.

Every project is built strictly adhering to the technical restrictions:
- **Pure Vanilla Web Technologies**: HTML5, CSS3, and modern JavaScript (ES6+).
- **Zero External Dependencies**: No third-party frameworks, libraries, React, Bootstrap, or server APIs.
- **Client-Side Persistence**: Browser `localStorage` used for bookmarking and state retention.
- **Full Responsiveness**: Seamless experience on laptops, tablets, and smartphones.

## 🚀 Quick Start / How to Run

1. **Clone or Extract**: Clone this repository or unzip `bosscoder_web_development_mini_projects.zip`.
2. **Open the Portal**: Double-click the root `index.html` in Google Chrome, Microsoft Edge, or Firefox.
3. **Launch Any Project**: Use the filter bar to browse by category (Games, Utilities, Lifestyle) and click **"Launch Project 🚀"** on any card.

## 👥 Suggested 3-Member Team Division of Work

For teams submitting one of these projects for their Bosscoder review, the work is cleanly modularized into 3 roles:
- **Member 1 (HTML & Structure)**: Document semantics, form inputs, accessibility labels, and initial template architecture.
- **Member 2 (CSS & Styling)**: Visual themes, typography hierarchies, card grids, 3D transforms, animations, and mobile media queries.
- **Member 3 (JavaScript & Logic)**: State management, event handlers, algorithmic calculations, canvas animation loops, and local storage persistence.
